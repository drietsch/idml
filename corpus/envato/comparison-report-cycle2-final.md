| newspaper / newspaper-template / -newsletter-layout | ~+1 ΔE each      | Q-03 inline-image color profile drift. SSIM −0.02 each. |

The trade-off pattern is consistent: Q-03 + Q-14 land *correct* behaviour
but compare slightly worse against InDesign's PDF rasterization, because:

- InDesign's PDF rasterizer uses the original CMYK ICC profile when
  rendering embedded JPEGs; our pipeline decodes through `image`
  crate's standard CMYK → sRGB which differs by a few ΔE.
- When the placeholder is removed (Q-14), the underlying frame fill
  doesn't yet match what InDesign would render (cover photo); the
  white-default fill ends up further from ref than the grey-X badge.

Both are unblock-paths for the proper fix, not the proper fix itself.
Closing the residual ΔE needs: streaming JPEG decoder for oversized
payloads (Q-14), embedded ICC profile threading (Q-03), and
auto-sized-frame measurement pre-pass (Q-02 renderer).
